# Security Policy

## Supported Versions

Only the latest release of MalSearch (`malsearch` on [PyPI](https://pypi.org/project/malsearch/)) receives security fixes.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report them privately through [GitHub's private vulnerability reporting](https://github.com/packing-box/python-malsearch/security/advisories/new) (the repository's *Security* tab, then *Report a vulnerability*). Please include:

- the MalSearch version and Python version;
- the steps to reproduce the issue (without sharing any API key);
- the impact you expect.

You will get an answer as soon as possible. Once the issue is confirmed, a fix is released and the advisory is published.
